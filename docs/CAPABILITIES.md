# Capability matrix vs typical QML apps (0.0.10)

**Implemented** = in the code and covered by `tests/ui.rs`, unit tests or the
real-window scenario. **Partial** = usable with the stated gaps.
**Planned** = intended, not in the code. **Unsupported** = not available.
lib-fltk-omarchy does not claim QML equivalence.

Per-OS behaviour (Linux Wayland/X11, macOS, Windows) is in the last
column and in [PLATFORMS.md](PLATFORMS.md).

| Area | QML typical | lib-fltk-omarchy 0.0.10 | Status | Platforms |
|---|---|---|---|---|
| Platforms | Qt runs everywhere | one `platform` module (dirs, appearance, fonts, primary modifier, CPU time) with a fallback per OS; the rest is portable | Implemented on Linux (tested); macOS/Windows type-checked, CI jobs ready | Linux Wayland + X11, macOS, Windows |

| Virtualized lists | ListView/TableView | `List` (count + row closure, selection, keyboard, wheel, thumb) | Implemented: `List`, virtual `table::Table` (sort, resizable columns) and lazy `table::Tree`, multi-selection by ID; `List::reorderable` (drag past 5 px with a drop line and edge scrolling, Alt+Up/Down); `from_model` variants redraw only changed rows, anchor the scroll on inserts above, keep selection by key | all |

| Drawing | Canvas/Shape | `gfx`: paths (Béziers, arcs, per-corner radii, squircles), anti-aliased fill/stroke with joins and caps, linear/radial/conic gradients, shadows, blur, layer opacity, blend modes, clip by shape, shape hit-testing; plus fltk-rs `draw` and `paint::*`; `chart`: `BarChart`, `LineChart` (keyboard cursor, readout, list items for screen readers, mirrored in RTL), `Meter` (segments, expected mark, warning/urgent tones) and `Ring`, cached as one image until data, size or theme change | Implemented (pixel-tested; [SHADERS.md](SHADERS.md)) | all |
